# SQL Portfolio Project: Retail & Inventory Analytics

## Overview
End-to-end SQL project analyzing sales, inventory, and supplier data for a retail chain.

## What's Inside
- 8 analytical SQL queries covering JOINs, CTEs, Window Functions, and Business KPIs
- Business insights and actionable recommendations for each query
- Mock dataset included

## Key Skills Demonstrated
- MySQL | CTEs | Window Functions (RANK, LAG, Running SUM)
- Inventory & Dead Stock Analysis
- Revenue Growth Tracking (MoM)
- Customer Segmentation (RFM)
- Supplier Performance Analysis
